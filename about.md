# Auto Decor

Select the blocks of a structure in the editor and press **Decor**. The mod builds an ornate decoration around and inside it:
nested frames, a heavy lintel, spires, dotted lines, dashes and vertical glow streaks.

* **Decor** – generate from the current selection (new random seed unless you set one in settings)
* **Reroll** – remove the last generation and make a different one from the same structure
* **Undo** – remove the last generation
* **Pal** – select one non-solid deco object and press this; every decor piece will use its ID

Styles: `gate`, `circuit`, `spiky`, `minimal`, `chaos`. The seed is shown after each generation; type it into settings to keep a result.

**Glow fade:** create a few color channels with the same color and decreasing opacity, list them in *Glow fade channels* (brightest first).
